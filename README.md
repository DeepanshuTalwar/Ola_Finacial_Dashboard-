# Ola Financial Dashboard – Power BI 100,000 Analysis

## Objective
Build a Power BI dashboard for analyzing **100,000 ride records** with a focus on business KPIs, customer behavior, and operational performance.

## Recommended Analysis Scope

### 1) Core KPIs
- Total Rides
- Total Revenue
- Average Ride Value
- Average Ride Distance
- Cancellation Rate
- Driver Utilization Rate

### 2) Time-Based Trends
- Daily rides and revenue trend
- Weekly peak-hour analysis
- Month-over-month growth

### 3) Geographic Insights
- Top pickup and drop locations
- Revenue by city/zone
- Heatmap of high-demand areas

### 4) Customer & Driver Insights
- New vs returning customers
- Customer lifetime value buckets
- Driver performance (rides, ratings, cancellations)

### 5) Payment & Cancellation Analysis
- Payment method distribution
- Cancellation reasons split
- Revenue leakage due to cancellations

## Suggested Dashboard Pages
1. Executive Summary
2. Demand & Revenue Trends
3. Geographic Analysis
4. Customer Insights
5. Driver & Operations
6. Cancellation & Payment Analysis

## Data Preparation Checklist
- Remove duplicate ride IDs
- Standardize date/time columns
- Validate missing values for fare, distance, and status
- Create derived columns (weekday, hour band, ride type)
- Add calculated measures in DAX for KPIs

## Outcome
This analysis structure supports scalable insights from a 100,000-row dataset and helps monitor growth, profitability, and operational reliability.
